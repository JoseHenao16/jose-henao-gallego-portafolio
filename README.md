# Portafolio de José David Henao Gallego

Portafolio personal desarrollado con Next.js, React, TypeScript y Tailwind CSS.

---

## Descripción

Este sitio presenta mi perfil profesional, formación, habilidades técnicas y una selección de proyectos web y geoespaciales. Las imágenes de perfil y portada, el correo y LinkedIn ya están configurados. Más adelante se pueden agregar imágenes de vista previa para los proyectos sin demo pública.

## Características principales

- Perfil y diálogo de contacto.
- Habilidades técnicas, idiomas y formación.
- Carrusel de proyectos con diálogos de detalle.
- Enlaces a GitHub, LinkedIn e Instagram y selector de tema.
- Componentes reutilizables organizados con Atomic Design.

## Tecnologías

- Next.js
- React
- Tailwind CSS
- React Icons

## Ejecución local

1. Abre la carpeta del proyecto:

```bash
cd JoseHenaoPortafolio
```

2. Instala las dependencias:

```bash
npm install
```

3. Inicia el servidor de desarrollo:

```bash
npm run dev
```

4. Abre http://localhost:3000 en el navegador.
